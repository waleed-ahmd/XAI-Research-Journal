- **Decision:** Switched the OpenAI model from "GPT-5.6 Luna" (which doesn't exist under that name) to GPT-5.6 Terra (`gpt-5.6-terra`).
  - **Why:** GPT-5.6 Terra is the mid tier of the GPT-5.6 family, which puts both models we're comparing at a comparable mid tier (Claude Sonnet 5.5 is Anthropic's "best combination of speed and intelligence" tier). Confirmed against OpenAI's current model docs rather than guessing.
- **Decision:** Added an explicit `effort` setting for Claude Sonnet 5.5 (`high`) alongside the existing `reasoning.effort` for OpenAI (`medium`), both now recorded in `harness/config.yaml` and included in the resumable-run hash.
  - **Why:** The Claude side was previously relying on the API's own default effort level without us ever stating what that was. Values were set to match current defaults exactly, so this is a documentation/traceability fix, not a behaviour change.
