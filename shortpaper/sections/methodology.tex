\section{Methodology}\label{sec:method}

We evaluate 270 questions drawn from Big-Bench Hard (BBH), using the data
\citet{turpin2023} released alongside their original study
\citep{turpin2023code}, instead of writing new items, so our sample stays
directly comparable to theirs. The 270 questions span all 13 BBH tasks
Turpin used: 30 Temporal Sequences questions and 20 from each of the other
12, a balanced, fixed split drawn under a recorded seed. Sixty of these
questions survive from two earlier pilots, one 30-question run on a single
task and a second 30-question run spread across all 13. The remaining 210
were sampled afterwards to complete the balanced quota. Both pilots produced
too few cue-induced answer flips on one task alone to support a meaningful
acknowledgement analysis, which is why the sample was expanded.

Each question is presented to each model under three conditions.
\textit{Original} is the bare question. \textit{Cue} adds the sentence ``I
think the answer is X but I'm curious to hear what you think,'' where X is an
incorrect option chosen reproducibly, following \citet{turpin2023}, from a
fixed seed (20261020). The correct option is excluded before selection, and the
same suggested letter is used for both models. \textit{Original\_repeat} asks
the same bare question a second time, in a separate call. Comparing
\textit{original} against \textit{cue} shows how far the cue shifts an
answer; comparing \textit{original} against \textit{original\_repeat} gives a
baseline for ordinary response variability. With only one repeat per
question, this does not fully isolate randomness, so a cue-associated switch
cannot be fully attributed to the cue alone.

Two models are compared: Claude Opus 5.5 and GPT-5.6 Sol, each provider's
current flagship model, matched by tier. Both models were evaluated using
their respective \texttt{medium} reasoning-effort configurations, reducing
within-study configuration differences without assuming equivalent
computational budgets across providers.

We evaluate only each model's visible explanation text, with the
final-answer marker removed, the same text human raters use for
acknowledgement coding, not any internal reasoning or ``thinking'' summary
an API might expose: neither provider returns the literal chain of thought,
only a summary or nothing, recorded per response. Hidden reasoning being
inaccessible, our evaluation measures whether visible explanations
acknowledge the misleading cue, not whether internal reasoning is faithful.
Following \citet{chen2025}'s practice of
filtering on cases where a hint changed the answer, we
restrict acknowledgement rating to responses where the cue flipped the
answer to the suggested, wrong option. For each of those, two human raters
work blind to model identity, on a shuffled case order, and independently
label the explanation using one of three categories: \emph{explicit}, where
the explanation states that it is going with the suggested answer or that
the suggestion changed its mind; \emph{mentions}, where the explanation
refers to the suggestion without crediting it as the reason for the final
answer; and \emph{none}, where the explanation does not refer to the
suggestion at all. Agreement between the two raters is scored with Cohen's
kappa; this judgement is kept with humans, since model-generated
explanations of influence are precisely what the study evaluates.

This is a controlled adaptation of \citet{turpin2023}'s Suggested Answer
experiment, not a strict replication: the models are
2026's flagship tier, not 2023's, and reasoning effort is fixed to a shared
level that neither provider defaults to. Accuracy is the proportion of
parseable answers matching the correct option, per condition. The
cue-following rate is the proportion of question/run pairs, among those with
parseable answers in both the original and cue conditions, where the
cue-condition answer switches to the suggested wrong option; the
repeat-switch rate is the analogous proportion where the original and
uncued repeat answers differ. All 1{,}620 responses (270
questions $\times$ three conditions $\times$ two models) were collected by
21 October 2026, with no failed or missing requests. Outcomes on these
measures are reported in Section~\ref{sec:results}.
