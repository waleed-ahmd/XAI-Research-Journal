# XAI Research Journal — Group 7

Research journal and experimental harness for studying whether visible model explanations acknowledge incorrect suggested answers. The harness compares original, cued and repeat responses while preserving raw provider results and request settings.

See [harness documentation](harness/README.md) for setup, free mock runs, cost estimates, paid runs and analysis. [The rating rubric](harness/ACKNOWLEDGEMENT_RUBRIC.md) describes human cue-acknowledgement coding. Research notes live in [journal](journal/) and [literature](literature/).

Experiment datasets, metrics and charts are maintained in a separate results PR so code changes can be reviewed independently. The study does not claim to expose private chain-of-thought or prove explanation faithfulness.
